1.	Створення структури Actions: У репозиторії створіть каталог .github/workflows/. У ньому створіть файл, наприклад, ci.yml.
2.	Використання Copilot для YML: У файлі ci.yml використовуйте Copilot для генерації робочого процесу (workflow) з наступними вимогами: ○ Trigger: Запускати акцію при push або pull request у гілку, що містить в назві develop чи master . ○ Job: Створити одну Job (наприклад, cross_build). ○ Strategy: Використати матрицю (strategy: matrix) для запуску білду на трьох ОС: ■ runs-on: ubuntu-latest (Linux) ■ runs-on: windows-latest (Windows) ■ runs-on: macos-latest (macOS) ○ Steps: Кожен білд повинен включати кроки: ■ Checkout коду (actions/checkout@v4). ■ Встановлення CMake (якщо потрібно). ■ Запуск команд конфігурації та білдування (запуск скрипту з Етапу 3). 

name: CI

on:
  push:
    branches:
      - '*develop*'
      - '*master*'
  pull_request:
    branches:
      - '*develop*'
      - '*master*'

jobs:
  cross_build:
    strategy:
      fail-fast: false
      matrix:
        os: [ubuntu-latest, windows-latest, macos-latest]
    runs-on: ${{ matrix.os }}

    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Install CMake on Linux
        if: runner.os == 'Linux'
        run: |
          sudo apt-get update
          sudo apt-get install -y cmake

      - name: Install CMake on macOS
        if: runner.os == 'macOS'
        run: |
          brew update
          brew install cmake

      - name: Install CMake on Windows
        if: runner.os == 'Windows'
        run: choco install cmake --installargs '"ADD_CMAKE_TO_PATH=System"' -y

      - name: Make scripts executable (Unix)
        if: runner.os != 'Windows'
        run: chmod +x ./ci.sh || true

      - name: Run CI script (Windows)
        if: runner.os == 'Windows'
        run: .\ci.cmd

      - name: Run CI script (Unix)
        if: runner.os != 'Windows'
        run: ./ci.sh

      - name: Upload build artifacts
        uses: actions/upload-artifact@v4
        with:
          name: project-build-${{ matrix.os }}
          path: build/**

      - name: Deploy (placeholder)
        run: |
          echo "Deploy step — replace this with your real deployment commands (upload to server, publish package, etc.)."
